Unscii 2.1 by Viznut (Ville-Matias Heikkilä), https://viznut.fi/unscii/

unscii-8.hex   8x8 glyphs, the system font at 320x240
unscii-16.hex  8x16 glyphs (a few 16x16), the system font at 640x480

Both files are the author's HEX distribution, unmodified, in the Unifont
hexdump layout: a hexadecimal codepoint, a colon, then one line of row
bytes with the most significant bit leftmost. The source package states
"Everything made by me (viznut) is in the Public Domain." Only
unscii-16-full carries GPL through its Unifont glyphs, and it is not used
here.
